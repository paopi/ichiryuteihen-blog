Minecraft のランチャーは開くのに、プレイボタンを押してもゲームが起動しない問題の解決策をまとめます。

## まず確認すること

### Java がインストールされているか確認

コマンドプロンプトで確認：

```bash
java -version
```

`java is not recognized` と出る場合は Java がインストールされていないか、PATH が通っていません。

**注意**: Java版 Minecraft はランチャーに Java が同梱されているため、通常は別途インストール不要です。ランチャーの設定で「同梱Javaを使用」が有効になっているか確認してください。

## 対処法1: ランチャーの設定を確認

1. Minecraft ランチャーを開く
2. 「インストール済み」タブを選択
3. 使用するバージョンの「...」→「編集」をクリック
4. 「その他のオプション」を開き、Java 実行ファイルが正しく設定されているか確認

## 対処法2: ランチャーを再インストール

1. コントロールパネルから Minecraft Launcher をアンインストール
2. `.minecraft` フォルダは削除しない（ゲームデータが消えます）
3. 公式サイトから最新のランチャーをダウンロードして再インストール

## 対処法3: グラフィックドライバーを更新

古いグラフィックドライバーが原因でクラッシュすることがあります。
NVIDIA なら GeForce Experience、AMD なら Radeon Software から最新ドライバーに更新してください。

## 対処法4: ログファイルを確認

クラッシュの原因がログに記録されています：

```
C:\Users\[ユーザー名]\AppData\Roaming\.minecraft\logs\latest.log
```

エラーメッセージで検索すると解決策が見つかることが多いです。

## まとめ

1. Java の状態確認（ランチャー同梱Javaを使う設定になっているか）
2. ランチャーの再インストール
3. グラフィックドライバーの更新
4. ログファイルでエラー内容を確認

それでも解決しない場合は Minecraft の公式フォーラムで検索してみてください。
